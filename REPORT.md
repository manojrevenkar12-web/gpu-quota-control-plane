What each design is:

- **As found**: As found: reservations held idle, unused ones kept, no moves, every quota request to a person, first come first served
- **Control plane**: The control plane: forecast-buffered lending, reclaim notices, rebalancing, scored quota requests, weighted fair share
- **Lend all idle**: Lend every idle node, no forecast buffer
- **No lending**: No lending of idle reserved nodes
- **No reclaim**: Unused reservations kept to the end
- **No rebalancing**: No moves between regions
- **Manual quotas**: Every quota request to a person
- **Approve all quotas**: Every quota request approved without a check
- **First come first served**: First come first served on contested capacity
